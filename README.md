# Financial Assets App

A React Native mobile application for browsing and analyzing financial assets, including stocks and cryptocurrencies. Users can filter assets by type, sort them by name or performance, and view detailed information about each asset.

## Features

- **Home Screen**: Displays a list of financial assets with options to filter by type (stocks, crypto, gainers, losers) and sort by name or daily performance.
- **Asset Detail Screen**: Shows detailed information about a selected asset, including its symbol, type, current price, daily change percentage, and a list of similar assets.
- **Responsive Navigation**: Built with `@react-navigation` for seamless transitions between screens.
- **Type Safety**: Uses TypeScript for robust type checking.
- **Testing**: Comprehensive unit and integration tests using Jest and `@testing-library/react-native`.
